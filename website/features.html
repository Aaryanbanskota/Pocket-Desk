Why PocketDesk?

🛡️

Privacy & Security

Zero cloud servers. Local Argon2id password authentication, password change in settings, and password-locked AI API key security in Isar DB.

🔄

Self-Hosted In-App Updates

Offline-first update check via raw GitHub releases with automatic download progress and seamless native Android package installer launch.

📡

Network File Share & PIN

Host files over local Wi-Fi with PIN access code so external devices without the app can instantly download files via a web browser link.

🤖

Universal AI Companion

Smart AI assistant integrated across Money Health, Note Formatting, Feed Comments, and a friendly Chat Buddy greeting you with "yo {username}".

💰

Money Health & Wallet

Track wallet balance, categorize expenses, and receive real-time AI spending scores (0–100) with financial breakdown insights.

⚡

Local P2P Sync

Instantly sync calendars, tasks, and notes with other devices via secure local WebSocket pairing using cryptographic AES-GCM-128 keys.

📲

Social Feed & Media

Offline local feed with image/video post attachments, like interactions, and automated contextual AI responses and comments.

📝

Rich Note Ecosystem & Preview

Tap notes to preview, auto-save on edit, checklists, attachments (images, PDFs, audio, drawings), trash/archive, and tags.
