Frequently Asked Questions

Does PocketDesk require an internet connection?

No. PocketDesk is designed to be 100% functional offline. Synchronization happens on your local Wi-Fi network directly peer-to-peer.

How is the data secured?

We use Isar database running secure local storage, local credentials hashed with Argon2, and syncing encrypted with AES-GCM-128.

Documentation & Setup

Setting up Local Sync

1. Open PocketDesk on both devices.

2. Go to Settings → Devices → Pair New Device.

3. Scan the QR code shown on the host device using the guest device camera. The P2P network handshakes automatically!
