🚀 Project Architecture & Code Entry Points

PocketDesk is built with Flutter and organized clean architecture. If you're a developer getting started:

  • lib/main.dart — The primary application entry point.
  • lib/main_dev.dart — Development build entry point.
  • lib/main_prod.dart — Production build entry point.
  • lib/core/theme/ — App colors, sizes, and fonts.

💡 Synchronization Guide

Go to Settings → Sync & Sharing to discover other devices. Scan the QR code or enter the WebSocket IP to pair your devices securely over your local network.
