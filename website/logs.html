Developer & Release Logs

Detailed change history, build updates, and architectural fixes for PocketDesk.

Feature & Rework Auth Rework, Supabase REST Sync & Account Badges
v1.3.0

Summary: Complete architectural overhaul of authentication flow, dynamic local/cloud registration, custom Supabase database profile synchronization, and device storage manager.

  • Dual sign-in for both Local and Supabase Cloud user accounts.
  • Gmail email validation & verification email dispatches.
  • Master Profile account status badges: Local User, Cloud Free, Cloud Pro, Pending Pro User.
  • Multi-account Check Data manager in Settings -> Privacy.
Fix Isar Database & Calendar Sync Integration
v1.2.0

Summary: Resolved database persistence rules for task priority filters and recurring calendar event scheduling.

  • Task sub-item checklist reordering handles.
  • Calendar timeline event notifications and alarm dispatcher.
Architecture P2P Local WiFi Network Encrypted Sharing
v1.0.0

Summary: Implemented local P2P WebSocket server with QR code scanner pairing for cross-device desktop and mobile session sharing.
