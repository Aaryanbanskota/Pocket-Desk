# PocketDesk Terms of Service

**Last Updated: September 27, 2026**

Welcome to **PocketDesk**. By using our local offline-first productivity application and tools, you agree to these Terms of Service.

---

### 1. Offline-First Privacy & Data Ownership
- **Local Data Storage**: All calendars, tasks, notes, wallets, AI API keys, and settings created in PocketDesk remain stored locally on your device in an Isar database.
- **Zero Cloud Servers**: PocketDesk does not host or retain your personal data on any cloud servers. You retain 100% ownership and control over your data.
- **Data Backup & Reset**: You are responsible for preserving your local data and encryption credentials. Using the 2-Step Account Deletion feature will permanently purge all local application data beyond recovery.

---

### 2. Device-to-Device P2P Sync & Local Share
- **Local Wi-Fi Pairing**: Device-to-device synchronization operates locally via encrypted WebSocket channels (AES-GCM-128).
- **Network File Share**: Local file sharing generates a temporary HTTP server on your local network. You are responsible for securing PIN codes when sharing access with other devices.

---

### 3. AI Integrations & API Keys
- **Third-Party Services**: Optional AI features interact with OpenRouter/LLM providers using the API keys you provide.
- **Key Storage**: Your API keys are encrypted locally using Argon2id password-protected storage. We do not transmit or store your API keys on external servers.

---

### 4. Software License & Updates
- PocketDesk is distributed under the open-source MIT License.
- In-app updates fetch public GitHub releases (`update.json` and APK binaries) without collecting user telemetry.
