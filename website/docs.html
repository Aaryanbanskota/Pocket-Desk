1. System Architecture & Entry Points

PocketDesk is built with Flutter (Dart 3.x) using Feature-First Clean Architecture and Riverpod state management.

lib/ ├── main.dart # Primary application entry point ├── core/ │ ├── router/app_router.dart # GoRouter auth-aware navigation │ ├── services/ │ │ ├── account_plan_service.dart # Local & Cloud plan state manager │ │ └── supabase_auth_service.dart # Supabase REST API & profile sync │ └── theme/ # App colors, padding, typography └── features/ ├── auth/ # Authentication & Profile pages ├── tasks/ # Task manager & priority models ├── notes/ # Rich notes & media attachments ├── calendar/ # Smart calendar & timeline events ├── money_tracker/ # Wallets & expense logging └── file_share/ # Local network P2P QR sharing

2. Database Engine & Supabase PostgreSQL Sync

PocketDesk uses a dual-layer database approach:

Local Storage Engine: Isar NoSQL local database stored securely on-device with zero network latency.
Cloud Sync Engine: PostgreSQL REST API on Supabase. A Postgres trigger automatically mirrors user creation to `public.profiles`:

-- PostgreSQL Trigger on auth.users -> public.profiles CREATE OR REPLACE FUNCTION public.handle_new_user() RETURNS trigger AS $$ BEGIN INSERT INTO public.profiles (id, email, username, display_name, account_type, account_plan, is_active, updated_at, created_at) VALUES ( new.id, new.email, COALESCE(new.raw_user_meta_data->>'username', split_part(new.email, '@', 1)), COALESCE(new.raw_user_meta_data->>'display_name', split_part(new.email, '@', 1)), 'cloud', 'free', true, now(), now() ) ON CONFLICT (id) DO NOTHING; RETURN new; END; $$ LANGUAGE plpgsql SECURITY DEFINER;

3. Pocket AI Mascot & OpenRouter API Setup

The Pocket AI Mascot integrates with OpenRouter API and local LLM backends. To enable AI assistance:

1. Go to Settings → AI Settings in your PocketDesk application.
2. Enter your OpenRouter API key.
3. Select your model: gpt-4o, anthropic/claude-3.5-sonnet, or google/gemini-flash-1.5.
4. Double tap anywhere in the app or highlight text to invoke the Pocket AI Mascot toolbar.

4. Peer-to-Peer QR Device Pairing

PocketDesk allows cross-device P2P transfer over local WiFi networks. Open Settings → Share Tab → Generate Login QR Code to share desktop sessions and files directly with companion devices without internet servers.
