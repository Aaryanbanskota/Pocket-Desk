Major Release v1.2.0 — Universal AI Companion, Money Health & Security Lock
v1.2.0 ▼

Summary: Integrated direct database Isar querying for reliable AI execution across all pages, added Argon2id password locking for API keys, Money Health dashboard, task/event previews, and rich note checklist ecosystem.

Key Features & Fixes:

  • AI Database Persistence: Direct Isar DB lookup (`AISettingsRepository`) eliminates transient provider initialization errors permanently across Money Health, Note Editor, Chat Buddy ("yo {username}"), and Feed.
  • Security API Key Lock: Password verification dialog (`AuthNotifier.verifyPassword`) prevents unauthorized access or modification to saved OpenRouter API keys.
  • Money Health & Wallet: Initial wallet balance setup, automatic calculation upon adding/editing expenses, category breakdowns, and AI Spending Score (0–100).
  • Task & Event Previews: Tapping tasks or calendar events displays detailed preview sheets with quick edit and delete icons.
  • Note Checklist & Editor: Added auto-save, archive, trash/restore, duplicate notes, rich markdown formatting, and media attachments.
  • FVM SDK Pinning: Pinned Flutter SDK version to 3.24.0 for build reproducibility.
